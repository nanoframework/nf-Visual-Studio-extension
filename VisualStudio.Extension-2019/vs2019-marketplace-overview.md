# .NET nanoFramework for Visual Studio 2019

**Write C#. Run it on a microcontroller. Debug it live.**

The .NET nanoFramework extension brings embedded development into the Visual Studio you already use. Create a project, deploy to your board, set breakpoints, step through code and inspect variables on the real hardware. You don't need C/C++ or a vendor toolchain.

> ℹ️ This extension targets **Visual Studio 2019**. Using Visual Studio 2022 or 2026? Get the [current extension](https://marketplace.visualstudio.com/items?itemName=nanoframework.nanoFramework-VS2022-Extension), which gets the latest features and fixes.

## What you get

- **Project templates** for apps, class libraries and unit tests
- **Deploy and debug on the device**: breakpoints, stepping, watch and call stack, running on the target
- **Device Explorer** to discover, connect, flash and manage boards
- **NuGet-based libraries** for GPIO, I2C, SPI, UART, PWM, ADC, networking, TLS and more
- **Familiar C# and .NET APIs**, including many from .NET IoT, so existing code and samples carry over

## What is .NET nanoFramework?

An open-source platform for running managed C# on constrained devices, such as IoT sensors, wearables, robots, maker projects and industrial equipment. It includes a compact CLR and a subset of the .NET base class libraries, so desktop .NET developers can work on embedded systems with the skills they already have.

## Supported hardware

- **Espressif**: ESP32, S2, S3, C3, C6, H2 and P4
- **STMicroelectronics**: STM32 F0, F4, F7, L4 and H7
- **Silicon Labs**: Giant Gecko GG11
- **NXP**: i.MX RT1060
- **Texas Instruments**: SimpleLink CC13xx and CC32xx
- **M5Stack**: Core, Core2, StickC and AtomS3
- **OrgPal**: PalThree and PalX
- **MXCHIP**: AZ3166

...and more, including community boards. [Full list](https://github.com/nanoframework/Home)
